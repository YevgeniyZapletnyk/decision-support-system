# Система підтримки прийняття рішень (Tkinter + MongoDB)

## Що реалізовано
- графічний desktop-інтерфейс на `tkinter`
- робота з альтернативами, критеріями та матрицею оцінювання
- введення та редагування оцінок у MongoDB
- 3 методи згортки: адитивна, мультиплікативна, обережна
- імпорт експертних ваг із CSV / Google Sheets CSV
- 3 методи узгодження експертних оцінок: середнє, медіана, усічене середнє
- порогова обробка альтернатив
- правила IF–THEN з бонусом, штрафом або виключенням альтернативи
- аналіз чутливості
- сценарний аналіз
- порівняння методів згортки
- текстове пояснення результату

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

## MongoDB
За замовчуванням використовується:
- URI: `mongodb://localhost:27017/`
- DB: `decision_support_system`

За потреби можна змінити через змінні середовища:
- `MONGODB_URI`
- `MONGODB_DB`
